nocap

Anti-screenshot, anti-AI display for secrets on screen.

Content is split into frames that alternate at your display's refresh rate. Each frame is noise; their mean is the content. Your visual system does the averaging, so you read it — a single screenshot does not. And the text never enters the DOM, so page-reading AI agents get nothing at all.

    How DevTools defeats it

    Listing a defeat without showing it invites the assumption it is theoretical. Both attacks run for real.

    The canvas must hold the correctly-arranged image or you could not read it either, so averaging a run of frames is the plaintext, and no mode changes that. scramble blunts the one-line fillText dump and keeps the value out of a heap search, but it is obfuscation, not encryption. The real line is automated pipeline vs. targeted attacker: nocap defeats the pipeline, never the person who decides to come after the value.

    What this defeats, and what defeats it

    ThreatResult
    Reflexive Print Screen / Win+Shift+S / ⌘+Shift+4Blocked
    DOM-reading AI agents, LLM scrapers, accessibility-tree readersBlocked absolutely
    Single-frame OCR / vision-model ingestionBlocked
    View Source, curl, Save Page As, Select-All + CopyBlocked
    Screenshot + a box blurWeakened
    Screen recording + temporal averagingDefeated
    Anyone with DevTools and intentDefeated

    The averaging limit is information-theoretic, not an implementation gap: anything your eye can integrate, software can integrate better. averageFrames() and denoisedLeak() ship so you can run both attacks against your own settings.

    Choosing colours

    color and background are the perceived colours — the split runs in linear light, so what you author is what you see. What you cannot escape is that a colour can only carry so much noise. Try the Unmaskable preset: exact colours, and a screenshot reads it outright.

    Masking ratioLeakVerdict
    ≥ 1.00.08 – 0.22good
    0.5 – 1.0~0.3fair
    < 0.50.47 – 0.95do not ship

    A channel at 0 or 255 has zero swing, so fully saturated colours cannot be masked at any lightness. The usable region is roughly channels in [40, 214], both colours mid-tone, separation under ~90. Put the secret on a mid-tone panel: it matches its surroundings exactly and has room to be protected.
